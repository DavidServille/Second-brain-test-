# CLAUDE.md

## Sync rule

This repo is a second brain used from both mobile and desktop. GitHub is the sync layer.

- After any change to files in this repo, commit and push to `master` immediately. Do not wait to be asked.
- Use short, plain commit messages describing what changed.
- Do not create branches or pull requests unless explicitly asked.
- Before making changes, pull the latest `master` so work from other devices isn't overwritten.
